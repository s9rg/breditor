# Metadata work admitted per call

Status: [source and independently installed qualification passed](qualification/2026-10-29-admitted-metadata-work.json): 518 direct checks, 25 installed checks, six strict source type stages and installed types. Nine per-call work laws are included. All thirteen V1 gates remain open.

An existing ordinary metadata store must remain excluded during native recovery. Changing its default permission or temporarily unlocking Core would also enable reentrant application callbacks. The internal work owner instead accepts explicit admission on a single synchronous staging call or one actual asynchronous job.

Admission comes from the genuine held native reservation for the exact Core. Copies, foreign cores, ended reservations and retired owners refuse before invoking the job. The ordinary store entry never receives that admission: ordinary methods still refuse inside and after the admitted callback.

Before invoking the callback, a separate one-job witness is added to the actual Core work registry and the original owner's pending-work set. The witness has the current native admission and accepts no further work. Both source retirement and native flag release must wait until the real promise settles. Disposal is not completion, and failure of another job cannot release this one.

Synchronous staging retains its witness through the actual callback. A later asynchronous write must own another explicit job. The type contract rejects an asynchronous staging return. A JavaScript caller that nevertheless returns a promise receives refusal, while its real promise and source attachment stay retained until settlement. Throws and promise rejections release only their own completed witness and retain the original error. A source retired during staging cannot detach until staging returns; asynchronous retirement retains its real attachment until every actual callback settles.

This supplies scheduling only. It does not authenticate a server decision, select a source/store, mutate native state, retry a failed save, acknowledge packets or activate a room. Constructor-owned metadata delivery ports must still pin exact source membership and original record formats, pass admission to private operations, retain native-first persistence and independently validate each network receipt.

Nine normal-Wasm laws cover ordinary exclusion, synchronous callback reentrancy, wrong/copy/stale admission, two overlapping late jobs, source retirement, throws/rejections and cold reuse of a later genuine reservation. Independently installed packages repeat these laws together with actual native owned-history receipt workflows. Node storage/locks are controlled fixtures; physical durability is not claimed.
