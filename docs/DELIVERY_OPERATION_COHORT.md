# Delivery and local operational cohort

Complete-delivery, restored-operation and three local-only parent families can
transfer their genuine native writers and complete upload stores through the
existing room handoff kernel. Each retains its own file, policy and provider
contract. This is private in-process custody, not durable physical catalog
adoption or room activation.

## Genuine reservations and atomic transfer

The closed router requires distinct IDs and genuine, correctly labelled parents.
It rejects empty or sparse inputs, duplicate owners, readiness-shaped objects and
wrong-family handles. Every parent becomes busy synchronously before policy or
factory verification begins. Existing upload custody is retained rather than
acquired a second time.

Preparation checks actual retained inputs, journal records, native histories,
version packets and whole upload stores. Result wrappers stay closed while
constructed. Current authority checks and temporary native-reader cleanup finish
before the last native/storage check. All reservations are consumed synchronously
only after every member passes. A failed check consumes no member. Released
coordinator connections reopen from their actual retained records on retry;
retired backup references are cleared only after successful disposal.

An interrupted storage acknowledgement does not imply a rolled-back transaction.
The existing journals reconcile exact committed and pending cuts. Neither a
phase marker nor the visible document tree replaces native history admission.

## Cancellation without final input callbacks

A reproduced failure allowed a later caller-supplied signal getter to change a
member that had already passed its final native check. An intrinsic signal read
alone is insufficient in Node, where an admitted Proxy can still run traps.

Borrowed read scopes now observe actual cancellation during preparation and
reserve their journal lifetime before that observation. The final check reads
private cancellation state, not caller properties or methods. Forged abort events
do not replace actual signal cancellation. Synchronous release retires the
observer without input callbacks; canonical listener removal follows the held
read lifetime in a later microtask, after cohort consumption finishes.

Real cancellation of any family refuses the whole handoff while preserving every
upload owner. Cancelling the last family's own executing guard retains its
existing authority-error wrappers and underlying cancellation cause. That error
contract is not changed to make the test pass.

## Source and provider lifetime

Complete-delivery and restored-operation parts retain their actual complete
source and uploads. Legacy local parts retain an `original` provider. Local
snapshot and flat-local parts retain an `input` provider. The selected document
policy stays in the source type; no complete-delivery source is relabelled as a
local-only provider.

Retiring a parent does not close its returned source or source-owned provider.
Literal inputs remain provenance, not backups of later edits. Native document
and comment Undo/Redo, retained review packets and versions, original-only pixels
and uploaded receipts keep their existing meanings.

## Functional qualification and remaining work

The [selected qualification](qualification/2026-10-23-delivery-operation-cohort.json)
passes 53 normal main stages. Source contracts pass 41 laws, including the plan
law; fresh installed packages pass 120 functional laws. Each source, fresh-package
and actual production-bundle probe passes forty five-writer cohorts: five native
profiles, four history pairs and two restored input kinds (`snapshot-v1` and
`lineage-v1`). Each preserves 400 exact handoffs and 200 cold continuations with
later edits, versions and both history lanes. Scope/capability masks rotate;
this is not their full Cartesian product or a mixed `lineage-v2` qualification.

The six existing journal, participant, restored source, restored parent, portable
export and lineage domains also pass all 640 cases in both source and installed
packages, with 1,920 future native history pairs per domain. The restored source
and parent matrices use snapshot inputs; their wire-one/wire-two counts describe
delivery transports, not graph input versions. Snapshot/flat cohort and native
incoming-source/catalog integration remain required checks.

The router retains its 1,024-member bound. Native/history, child journal and asset
limits remain unchanged. No public-root API, file protocol, default storage
choice or native runtime changes. Controlled storage is not physical durability.

Seven-family durable catalog adoption, complete retained-copy/provider/client
reconciliation, authenticated activation and sustainable native history remain
required. Separate seven-family and durable-coordinator prototypes are not
promoted by this checkpoint. Full feature parity and all thirteen V1 release
gates remain open.
