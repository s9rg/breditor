# Metadata inspection of a recovered cold target

Status: qualified private component; source and independently installed packages
each pass all twelve mandatory cases.
Full joint activation and the thirteen V1 release gates remain separate work.

A cold executor can have a genuinely promoted successor after its construction
reader has ended. The SDK-private `withColdRoomExecutionMetadataTarget` action
keeps that actual successor inside its recipient during a finite inspection.
Original cleanup must finish first. Saved phase labels, copied prototypes and
archived descriptors cannot manufacture this runtime ownership or its witness.

The witness identifies the actual run and the native cut returned by promotion.
It is valid only for that selected recovery scope and expires when the visit
ends. Actor locks stay held and Take remains excluded through admission,
reflection, asynchronous work and cleanup. The shared witness contract lets
metadata continuation validate a cold target with the same rules as a warm one.

Each visit uses fresh read options, a fresh authority check and its own command
cancellation. Cancelling the completed construction reader does not revoke a
still-owned successor. A denied fresh authority check still prevents access.
Terminal Close independently stops target work and construction work, joins the
actual visit and closes borrowers before releasing actors. Cancellation never
reopens the old editor or grants an application a recovered owner.

The focused cases use genuine interrupted seven-family execution and fourteen
fresh actor locks, actual Native histories and raster data, with controlled
browser storage/locks. They check early refusal, reflection reentry, scoped
witness revocation, command cancellation, close draining, old-reader cancellation
and future document/comment Undo/Redo. Existing cold execution and source/metadata
lifetime cases remain part of the mandatory component commands.

Run `node scripts/check-cold-target-metadata-source.mjs` and
`node scripts/check-cold-target-metadata-installed.mjs` after building the SDK
and existing Native fixtures. Neither command certifies physical crash durability,
complete cold joint publication, full policy matrices or product release.
Original wire/record formats, Rust, normal Wasm, public root exports and versions
are unchanged.
