# Held actors during target recovery

The private target recovery route connects a genuine stopped actor cohort to
the concrete seven-family operational recovery engine. Temporary editors borrow
the same actual writer resources sequentially; the final editor receives release
ownership only through an explicit whole-cohort promotion. Normal begin, resume,
Close, stored formats and public root exports keep their existing meanings.

## Actual resources and explicit target identities

The caller retains the real StoppedActorCohort before opening a target root.
beginPhysicalRootKeepingActors and resumePhysicalRootKeepingActors require that
genuine object, including at JavaScript runtime. Missing or fabricated custody
refuses before reading target options or reserving storage. Neither a saved phase
nor an actor ID supplies writer ownership.

Whole target preflight compares the complete member set, source family, room,
document writer and comment actor. Each member has an explicit final namespace
and, where required, a separate recovery-source namespace. A route cannot borrow
for another identity or an undeclared namespace.

The existing native constructors remain responsible for real source admission,
storage reads and native lifetime. Four constructors privately register their
exact document and optional review lease handles. The final check uses this
registration and the genuine native read registry; a valid readonly native replay
with matching history is not a replacement writer. No mutable core or lease
getter is added to a read capability.

## Sequential staging and final construction

DeferredActorLeaseInput selects no serialized field and acquires no actor by
itself. Known SDK policy snapshots and origin/journal wrappers explicitly forward
the existing private route. Ordinary options acquire no private ownership through
this forwarding. Function identity is not a custody key.

Only the concrete native constructor takes a loan. Before another constructor
borrows, the previous document and review handles must actually have returned.
A pending constructor, a live staging editor or failed cleanup that still owns
either handle refuses another borrower. Untaken slots can be returned by canonical
cleanup after construction failure without releasing the global writer locks.

Original and generation recovery may reopen the same native namespace while
reapplying current policy. Independent recovery stages a separate source before
opening its journaled final source. Graph recovery may reopen a source repeatedly
while replaying retained cuts. All use the same explicit route through these
sequential constructors; none releases and reacquires the writer between them.

## Final admission and promotion

finish checks the actual complete final native sources in addition to the existing
catalog, component, journal and packet checks. Each final source must hold the
exact current loan at its declared final namespace. A staging source cannot pass
merely because the escrow reports a borrower.

Every routed member is checked again before the cohort's first promotion.
Promotion makes the actual final handles normal release owners; a caller's
promoted flag cannot substitute that transfer. Closing a route never closes the
cohort's escrow or its global writer locks. The caller remains responsible for
the actor cohort, actual target root and failed cleanup until final handoff.

Closing the unpromoted target root first closes its actual children, then returns
the routes. The same caller-held cohort can then resume the existing target
journals with fresh policy. Even completed journal rows require actual stores and
native reopens; their marker never manufactures a source.

## Boundary of this implementation

This is the warm actor-resource route, not the complete mutable room executor.
The [immutable execution intent](NATIVE_ROOM_EXECUTION.md) keeps its one-record
schema. A separately and explicitly named START journal must bind that intent,
retain per-target progress and keep an actual executor owner reachable before
irreversible retirement. Complete selected-upload adoption and the final common
native, packet, asset and ownership barrier still belong to that executor.

A cold process must acquire real actor locks through an explicit path. Saved
resource descriptions cannot recreate them. Local writer exclusion also does not
provide provider reconciliation, authenticated cross-device activation or
sustainable history retention. Those remain V1 architectural requirements;
cosmetic and browser-specific work does not close them.
