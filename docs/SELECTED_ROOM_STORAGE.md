# Portable selected-room storage

Status: SDK-private implementation; source and actual offline-installed functional qualification passed. All thirteen V1 gates remain open. This extends the original data formats; it does not relabel them or change public defaults.

Capture requires the genuine selected native recovery scope. It settles the constructor-owned native saves and original packet stores, retains a complete current room file and captures the actual component namespaces declared by that root, catalog and asset adoption. A local-review bundle is explicit or null. Supplied database lists are never accepted. Current document journals, history heads/files and packet caches are projected by their independently admitted writer/room/cache keys so unrelated records are excluded. Dedicated component stores retain their complete declared contents. Every selected record is reread and typed-hashed, and the final complete current cut must remain unchanged before export returns. Actual packet/native/asset parents stay owned throughout.

The new contiguous archive has a closed canonical header, an explicit typed-value graph and complete binary pieces. Whole-file and per-piece hashes, exact lengths, all graph references and absence of unused pieces/tail bytes are verified. Binary data is not squeezed through JSON: Blob/File metadata, ArrayBuffers, view offsets, undefined, special numeric values, dates, aliases, maps, sets, cycles and sparse arrays have explicit tags. Executable objects, accessors, unsupported prototypes and hidden fields are refused. Built-in value tags accept only their intrinsic state; custom own properties, subclasses and resizable ArrayBuffers are refused because they are not represented by those tags. Ordinary object properties and supported array properties remain explicit graph edges. Input descriptors and buffers detach synchronously before the first asynchronous byte/hash callback. Disposing an archive drops its bytes and authority links; each internal content read decodes a fresh graph.

The complete file has a one-GiB bound, graph JSON 256 MiB and header 16 MiB. Per-source/native limits stay unchanged. The implementation refuses an oversized complete export rather than dropping history or uncommitted work. No auto-increment store is accepted because its hidden key-generator state cannot be inferred from existing rows. The existing seven component families use explicit keys. Unsupported component schemas are refused rather than migrated.

Restore reserves all selected destination namespaces through bounded custody groups and actual origin-wide leases. A preview probes absent databases without leaving placeholders and reports each destination's complete typed fingerprint and missing/present state. A new approval is required; the same complete inspection repeats afterward. Existing selected values must match exactly, including binary bytes. Only missing keys are added; no existing record is put, replaced or deleted. Unrelated keys/stores in supported shared document databases stay intact. Missing stores, incompatible schema, additional selected history or conflicting values refuse restoration. Complete reads after each write and at final return prove the selected data. A competing non-cooperative write can cause refusal but never causes this code to overwrite it.

IndexedDB cannot atomically commit across databases. Each database's additions are atomic; earlier committed data remains if a later copy or permission check fails. Retry requires a new observed destination choice and fresh approval. Late requests, namespace reservations and cleanup failures retain actual exclusion until drained. No actor, writer, source, backend or activation permission is saved in the archive or restore result.

Restored data is not an editable room. The host must separately supply current independent factories/policies, reopen the actual physical operation, and pass the complete archive current file through the normal cold-selected-room preview/approval/admission. That proves native document/comment/packet/asset continuation before returning an editable selected owner. Network delivery additionally requires the normal fresh authenticated current-path admission; cached counters and receipts do not grant it.

Functional qualification uses the normal Wasm and actual native service: save/read a portable file, restore all selected databases into a fresh controlled origin, inject a real partial-copy failure, require fresh retry, reopen seven new native owners with offline work, obtain renewed authenticated receipts for all three local review streams and verify future document/review Undo/Redo. The source and independently installed packages must both execute this flow. This is not physical browser crash durability or cross-device fencing evidence.

Still open: explicit database/server renaming, metadata dependencies outside the declared selected root/local-review bundle, complete proposal/revision/version transport custody, joint provider/client/assets reconciliation and authenticated whole-room activation, public API stabilization, sustainable large-history cost and full V1/parity qualification. Existing original protocols, source-family meanings and package versions remain literal.
