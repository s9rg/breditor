## First publication and later saves

paired source acquires both native writer leases, restores verified input LIVE,

Prepare stores one exact pending cut before native publication. Acknowledge
requires exact native source readback. Each journal update compares the entire
selected intent and retained rows; a pending cut cannot be replaced. Cold reopen
selects the acknowledged or pending cut only when the actual native store agrees.

## Ownership and fresh reads

A successful source privately owns journal cleanup, its read-only input-LIVE
anchor and incoming archive. An unreturned source abandons only its reservation;
the journal remains available for explicit retry. Failed release retains the same
actual cleanup owners rather than recreating a disposed native editor.

Independent authorized read scopes remain available after a write grant or signal
ends. They hold actual journal/input/native lifetime, have a bounded reentry count,
and release on failure. Source close waits for held reads. A final callback that
changes native publication invalidates a captured value. Mutable public facade
methods and structural ready objects establish no ownership.
